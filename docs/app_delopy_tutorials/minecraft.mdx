# Minecraft 联机教程

## 介绍

- 本文档将介绍如何使用 NatureTunnel 内网穿透实现 Minecraft 与好友联机，以及在本机搭建 Minecraft 内网穿透服务器以更方便地联机。
- 以下教程均使用 Java 版 Minecraft 26.2 与 Fabric 模组演示。

## 操作步骤

### 一般联机

1. 为您的 Minecraft 安装「更高级联机设置（LAN World Plug-n-Play）」模组。

![模组](https://docs-assets.bucket.uciu.cn/images/Image_467977139075278.png)

2. 启动 Minecraft Java 版，进入世界后打开游戏菜单（Esc），点击 **对局域网开放**。

![游戏菜单](https://docs-assets.bucket.uciu.cn/images/Image_467978127701111.png)

3. 设置联机选项：

    - 多人游戏：局域网
    - 正版验证：关（若均有正版账号则可忽略）
    - 端口号：任意（1024-65536）
    - 白名单：关

![联机设置](https://docs-assets.bucket.uciu.cn/images/Image_467979068708559.png)

4. 点击 **应用更改**。

5. 在浏览器中打开 [创建隧道](https://console.nrtun.com/tunnel/create) 页面，选择一个节点创建隧道。

6. 隧道名称任意，本地端口填写刚刚在游戏中输入的端口，本地主机无需修改，远程端口随机选择一个，高级选项无需修改。

![创建隧道](https://docs-assets.bucket.uciu.cn/images/Image_467980062836684.png)

7. 进入 [隧道列表](https://console.nrtun.com/tunnel/list)，点击隧道下的齿轮图标，选择 **查看详情**，将服务地址（形如 `xxxxxx.xxx.xxxx:*****`）全部复制并发送给您的好友。

![服务地址](https://docs-assets.bucket.uciu.cn/images/Image_467981047983454.png)

8. 打开 NrtunLauncher 图形化客户端，进入 **隧道管理**，启动您刚刚创建的隧道。

![启动隧道](https://docs-assets.bucket.uciu.cn/images/Image_467981994527412.png)

9. 回到游戏，等待好友进入，即可开始游玩。

### 服务器联机

以下步骤介绍如何在本机搭建 Fabric 服务器并实现开机自启。

1. 在浏览器中打开 [Fabric 服务器下载页](https://fabricmc.net/use/server/)，选择对应的版本下载 `.jar` 服务端文件。

![下载服务端](https://docs-assets.bucket.uciu.cn/images/Image_467983012958401.png)

2. 新建一个文件夹，将下载好的 `.jar` 文件拖入，并复制完整文件名（含后缀）。

![新建服务器文件夹](https://docs-assets.bucket.uciu.cn/images/Image_467984166780536.png)

3. 新建一个 `.bat` 文件并用记事本编辑，输入以下内容：

```bat
java -Xms<最小内存> -Xmx<最大内存> -jar <文件名> nogui
```

::::note
`Xms` 后填写最小分配内存，`Xmx` 后填写最大分配内存，格式为 `*G`；实际输入时无需保留括号。
::::

![配置启动文件](https://docs-assets.bucket.uciu.cn/images/Image_467985239208765.png)

4. 双击启动该 `.bat` 文件。

5. 运行完成后，打开 `eula.txt`，将 `eula=false` 修改为 `eula=true`。

![同意协议](https://docs-assets.bucket.uciu.cn/images/Image_467972399618301.png)

6. 用记事本打开 `server.properties` 并编辑：

    - `simulation-distance`：视距
    - `spawn-protection`：出生点保护格数
    - `view-distance`：模拟距离
    - `difficulty`：游戏难度（easy、normal、hard）
    - `online-mode`：是否开启正版验证
    - `server-port`：服务器端口

7. 将需要使用的模组放入 `mods` 文件夹。

8. 双击启动该 `.bat` 文件开服。

## 使服务器能被好友加入

1. 在浏览器中打开 [创建隧道](https://console.nrtun.com/tunnel/create) 页面，选择一个节点创建隧道。

2. 隧道名称任意，本地端口填写 `server.properties` 中 `server-port` 后的数字，本地主机无需修改，远程端口随机选择一个，高级选项一般无需修改。

![创建隧道](https://docs-assets.bucket.uciu.cn/images/Image_467980062836684.png)

::::note
如需获取玩家的真实 IP，请在高级选项中开启 Proxy Protocol，具体请参考控制台配置。
::::

3. 进入 [隧道列表](https://console.nrtun.com/tunnel/list)，点击您创建的隧道下的齿轮图标，选择 **查看详情**，将服务地址（形如 `xxxxxx.xxx.xxxx:*****`）全部复制并发送给您的好友。

![服务地址](https://docs-assets.bucket.uciu.cn/images/Image_467981047983454.png)

### 客户端法

1. 打开 NrtunLauncher 图形化客户端，进入 **隧道管理**，启动您刚刚创建的隧道。

![启动隧道](https://docs-assets.bucket.uciu.cn/images/Image_467981994527412.png)

2. 回到服务器，等待好友进入，即可开始游玩。

### 命令行法

1. 在官网 [软件下载](https://console.nrtun.com/release) 页面，找到 NrtunCore，选择合适的 `.exe` 程序下载。

![下载exe](https://docs-assets.bucket.uciu.cn/images/Image_467973538192051.png)

2. 在电脑任意位置新建一个文件夹，将下载好的 `.exe` 文件拖入其中。

3. 在该文件夹中新建一个名为 `configs` 的文件夹。

![新建文件夹](https://docs-assets.bucket.uciu.cn/images/Image_467975263527727.png)

4. 回到官网 [隧道列表](https://console.nrtun.com/tunnel/list)，点击齿轮图标，选择 **生成客户端配置**，下载 `.toml` 配置文件。

![客户端配置](https://docs-assets.bucket.uciu.cn/images/Image_467976204079862.png)

5. 将下载的 `xxxx.toml` 重命名为 `client.toml`，并拖入 `configs` 文件夹。

6. 退回上一级文件夹，双击启动 `.exe` 文件。

7. 回到服务器，等待好友进入，即可开始游玩。

## 配置开机自启（命令行法，Windows）

1. 按下 `Win + R`，输入 `taskschd.msc` 并回车，打开任务计划程序。

2. 创建基本任务：名称随意，触发条件选择 **计算机启动时**，操作选择 **启动程序**，程序或脚本输入 `cmd.exe`。

3. 添加参数，输入：

```
/k cd /d "[exe所在目录(不含exe)]" && "[exe]"
```

::::warning
引号必须保留。
::::

4. 完成后即可实现开机自启。
