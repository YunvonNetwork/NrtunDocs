# NatureTunnel 命令行交互式客户端操作文档

## 介绍

- 本文档介绍如何使用 NatureTunnel 命令行交互式启动器启动隧道。
- 启动器提供全中文的操作界面，支持 Windows、Linux、macOS、FreeBSD 以及多种路由器等设备。

## 准备工作

1. 一台用于搭建服务并启动隧道的设备。

2. 在 NatureTunnel 控制台 [软件下载](https://console.nrtun.com/release) 页面，下载适用于您系统架构的 NatureTunnel 命令行交互式启动器。

3. 在 NatureTunnel 控制台 [创建隧道](https://console.nrtun.com/tunnel/create) 页面，根据您的本地服务类型创建所需隧道。

## 启动隧道

1. 启动下载的启动器文件。

![启动器启动画面](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%202.png)

2. 按照界面指引打开浏览器授权链接，使用您的 NatureTunnel 账号完成登录授权。

![设备授权链接](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%203.png)

![授权状态](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%204.png)

3. 使用方向键、鼠标滚轮或 `j/k` 键选择需要启动的隧道，按 `Enter` 启动。

![选择隧道](https://docs-assets.bucket.uciu.cn/images/tui-prac/image.png)

4. 等待片刻，隧道启动成功后即可正常访问您的服务。

![隧道启动成功](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%201.png)

:::note
隧道运行期间请保持启动器窗口开启，按 `Ctrl+C` 可停止隧道。
:::

## 快捷命令

:::note
以下示例中的文件名为各平台发布产物的示例名称，实际使用时请以您下载的二进制文件名为准。
:::

直接启动：

Windows PowerShell：

```powershell
.\nrtun_tui_cli-windows-amd64.exe
```

Linux：

```bash
./nrtun_tui_cli-linux-amd64
```

macOS：

```bash
./nrtun_tui_cli-darwin-arm64
```

FreeBSD：

```bash
./nrtun_tui_cli-freebsd-amd64
```

直接指定隧道启动（无需进入选择界面）：

```powershell
.\nrtun_tui_cli-windows-amd64.exe --tunnel-id tun_xxx
```

也可以把隧道 ID 直接放在命令后面：

```powershell
.\nrtun_tui_cli-windows-amd64.exe tun_xxx
```

只测试登录，不启动隧道：

```powershell
.\nrtun_tui_cli-windows-amd64.exe --login
```

退出登录：

```powershell
.\nrtun_tui_cli-windows-amd64.exe --logout
```

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--tunnel-id <id>` | 直接指定要启动的隧道，跳过隧道选择界面 |
| `--login` | 只执行登录，不启动隧道 |
| `--logout` | 退出登录，删除本地保存的登录信息 |
| `--api-base-url <url>` | 自定义 API 地址，一般用户无需使用 |
| `--help` / `-h` | 显示帮助信息 |

如果同时使用 `--tunnel-id` 和位置参数指定隧道，以 `--tunnel-id` 为准。

## 界面操作

### 授权页面

- 按 `r` 重新获取授权链接。
- 按 `Esc` 或 `q` 取消授权。
- 按 `Ctrl+C` 退出程序。

### 隧道选择页面

| 按键或操作 | 操作 |
| --- | --- |
| `↑` / `k` | 选择上一项 |
| `↓` / `j` | 选择下一项 |
| `PageUp` / `PageDown` | 按页翻动 |
| `Home` / `End` | 跳到第一项或最后一项 |
| 鼠标滚轮 | 上下移动选择 |
| 鼠标左键 | 选择并启动点击的隧道 |
| `Enter` | 启动当前选中的隧道 |
| `Esc` / `q` / `Ctrl+C` | 取消选择 |

## 登录状态

首次授权登录后，启动器会在同目录下生成 `.nrtun_credential` 文件，下次打开启动器无需再次登录授权，可以直接选择隧道启动。

如需重新登录，删除该文件即可。

:::warning
该文件包含您的登录凭据，请勿分享或上传。
:::

## 常见问题

### 授权页面一直等待

请确认：

- 浏览器打开的是当前界面显示的授权链接。
- 输入的是当前显示的验证码，而不是旧验证码。
- NatureTunnel 账号已正常登录。
- 网络可以正常访问 NatureTunnel 服务。

可以按 `r` 重新获取授权链接。

### 隧道列表为空

请先在 NatureTunnel 控制台创建隧道。

### HTTPS 隧道无法启动

请确认：

- 您已完成实名认证。
- HTTPS 隧道已申请并绑定证书。

### 双击 Windows 程序后窗口立即关闭

程序遇到错误时会显示错误信息。请使用命令行方式启动，以便查看完整错误信息：

```powershell
.\nrtun_tui_cli-windows-amd64.exe
```
