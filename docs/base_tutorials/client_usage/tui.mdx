# NatureTunnel 命令行交互式客户端操作文档

## 介绍

- 本文档将介绍如何使用 NatureTunnel 命令行交互式启动器（NrtunTerminalLauncher）启动隧道。
- 该客户端通过 OAuth 2.0 Device Code 完成用户授权，从 NatureTunnel Open API 获取隧道和证书配置，自动生成 NrtunCore 所需的 `active.toml` 并启动内嵌的 NrtunCore。
- 提供全中文 TUI，支持 Windows、Linux、macOS、FreeBSD 以及多种路由器和嵌入式 Linux 架构。
- 使用过程中无需在命令行输入 `user_id`、`user_secret` 或 OAuth `client_id`。

## 主要功能

- 使用 OAuth 2.0 Device Code 登录 NatureTunnel，官方内置 public OAuth client，无需用户配置 `client_id`。
- 支持 TCP、UDP、HTTP 和 HTTPS 隧道。
- 支持通过方向键、`j/k`、鼠标滚轮或鼠标点击选择隧道。
- 支持通过 `--tunnel-id` 或位置参数直接指定隧道。
- 自动生成 NrtunCore 的 `active.toml` 并启动 Core。
- OAuth access token 失效时，自动通过 refresh token 刷新并重试一次请求。
- HTTPS 隧道自动获取、校验证书与私钥，并安全写入本地数据目录。

## 准备工作

1. 一台用于搭建服务并启动隧道的设备。

2. 在 NatureTunnel 控制台 [软件下载](https://console.nrtun.com/release) 页面，下载适用于您系统架构的 NrtunTerminalLauncher（NatureTunnel 命令行交互式启动器）。

3. 在 NatureTunnel 控制台 [创建隧道](https://console.nrtun.com/tunnel/create) 页面，根据您的本地服务类型创建所需隧道。

## 快速开始

### 直接启动

Windows PowerShell：

```powershell
.\nrtun-cli.exe
```

Linux、macOS 或 FreeBSD：

```bash
./nrtun-cli
```

不传入隧道 ID 时，程序会根据 `.nrtun_credential` 凭据文件是否存在决定流程：

- **首次运行**：执行 OAuth 授权 → 选择隧道 → 启动，并自动保存凭据。
- **再次运行**：凭据有效时跳过 OAuth 授权页，直接进入隧道选择 → 启动。
- **凭据过期或已删除**：回退到首次运行流程。

### 指定隧道

```powershell
.\nrtun-cli.exe --tunnel-id tun_xxx
```

也可以将隧道 ID 作为第一个位置参数：

```powershell
.\nrtun-cli.exe tun_xxx
```

指定隧道 ID 时，CLI 仍会优先尝试凭据刷新以跳过 OAuth 授权，然后直接启动指定隧道。

### 仅测试登录

```powershell
.\nrtun-cli.exe --login
```

该命令只完成 OAuth Device Code 登录并保存 token，不选择或启动隧道。

### 退出登录

```powershell
.\nrtun-cli.exe --logout
```

程序会尝试吊销已保存的 refresh token，并删除本地 `auth.json` 和 `.nrtun_credential` 文件。远端吊销失败不会阻止本地授权文件被删除。

## 启动隧道（交互流程）

1. 启动下载的启动器可执行文件。

![启动器启动画面](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%202.png)

2. 按照界面指引打开 OAuth 设备授权链接，完成授权。

![设备授权链接](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%203.png)

![授权状态](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%204.png)

3. 使用方向键、鼠标滚轮或 `j/k` 选择需要启动的隧道，按 `Enter` 启动。

![选择隧道](https://docs-assets.bucket.uciu.cn/images/tui-prac/image.png)

4. 等待片刻，隧道启动成功后将进入运行状态。

![隧道启动成功](https://docs-assets.bucket.uciu.cn/images/tui-prac/image%201.png)

:::note
NrtunCore 建立隧道会话后会保持前台运行，按 `Ctrl+C` 可停止。
:::

## 命令行参数

当前支持的完整参数如下：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--tunnel-id <id>` | 字符串 | 空 | 直接指定要启动的隧道，跳过隧道选择界面 |
| `--api-base-url <url>` | 字符串 | `https://api.console.nrtun.com` | 覆盖 NatureTunnel API 基础地址，主要用于开发、测试或私有部署 |
| `--login` | 布尔开关 | `false` | 只执行 OAuth Device Code 登录，成功后退出 |
| `--logout` | 布尔开关 | `false` | 吊销并删除本地保存的 OAuth 授权信息 |
| `--help` / `-h` | 布尔开关 | `false` | 显示命令行帮助 |

位置参数支持：

```text
nrtun-cli <tunnel-id>
```

如果同时提供 `--tunnel-id` 和位置参数，以 `--tunnel-id` 为准。

已经移除且不再支持的参数：

```text
--client-id
--user-id
--user-secret
```

OAuth public `client_id` 已内置在官方 CLI 中，用户不能通过参数覆盖。

## 环境变量

| 环境变量 | 说明 |
| --- | --- |
| `NRTUN_API_BASE_URL` | 覆盖默认 API 地址，优先级低于 `--api-base-url` |
| `NRTUN_CORE_BINARY` | 指定外部 NrtunCore/`natc` 可执行文件路径，优先级高于内嵌 Core 和同目录 Core |

API 地址优先级：

```text
--api-base-url
NRTUN_API_BASE_URL
https://api.console.nrtun.com
```

## TUI 操作

### OAuth 授权页

授权页会显示：

- 浏览器授权链接。
- 用户验证码。
- 验证码剩余有效期。
- 当前授权状态。

操作键：

| 按键 | 操作 |
| --- | --- |
| `r` | 重新申请设备验证码 |
| `Esc` / `q` | 取消授权 |
| `Ctrl+C` | 终止程序 |

设备码过期后，程序会自动申请新的设备码。对于 `authorization_pending` 和 `slow_down`，程序会按 OAuth Device Code 规范继续等待或调整轮询间隔。

### 隧道选择页

| 按键或操作 | 操作 |
| --- | --- |
| `↑` / `k` | 选择上一项 |
| `↓` / `j` | 选择下一项 |
| `PageUp` / `PageDown` | 按页移动 |
| `Home` / `End` | 跳到第一项或最后一项 |
| 鼠标滚轮 | 上下移动选择 |
| 鼠标左键 | 选择并启动点击的隧道 |
| `Enter` | 启动当前选中的隧道 |
| `Esc` / `q` / `Ctrl+C` | 取消选择 |

列表项会显示隧道名称、协议、远程端口或域名以及隧道 ID。

## 凭据与登录状态

- 首次完成 OAuth 设备授权后，启动器会在可执行文件同目录下生成 `.nrtun_credential` 凭据文件。
- 当该文件存在且有效时，下次打开启动器无需再次授权，可直接选择隧道启动。
- 如需重新登录，手动删除该文件即可；程序也会在凭据失效（token 过期或被吊销）时自动删除该文件，并回退到完整授权流程。
- 凭据只用于跳过 OAuth 授权，不会记忆隧道选择。每次启动仍需选择隧道，或通过 `--tunnel-id` 直接指定。

:::warning
本地保存的授权文件包含敏感凭据（如 OAuth refresh token），请勿上传、分享或提交这些文件。
:::

## 常见问题

### 授权页一直显示等待

确认：

- 浏览器打开的是当前 TUI 显示的授权链接。
- 输入的是当前设备码，不是已经刷新或过期的旧设备码。
- NatureTunnel 账号已正常登录。
- 系统可以访问 `api.console.nrtun.com` 和 `console.nrtun.com`。

可以按 `r` 重新获取设备码。

### 当前账号没有可用隧道

OAuth 授权成功，但隧道列表为空。请先在 NatureTunnel 控制台创建并配置隧道。

### HTTPS 证书获取失败或返回 403

确认：

- 用户已完成实名认证。
- token 包含 `certificate:read`。
- 隧道存在 `options.bindCertId`。
- 证书属于当前授权用户且内容已就绪。

### 提示 `nrtun core binary not found`

当前 CLI 构建没有内嵌 Core，且未找到外部 `natc`。请使用官方 Release 单文件产物，或通过 `NRTUN_CORE_BINARY` 环境变量指定 NrtunCore 路径（见「环境变量」）。

### 双击 Windows 可执行文件后窗口立即关闭

不带参数双击运行时，CLI 遇到错误会显示错误并等待按键。使用命令行启动可以看到更完整的上下文：

```powershell
.\nrtun-cli.exe
```
