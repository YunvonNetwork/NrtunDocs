# NatureTunnel Windows 图形化客户端操作文档

## 介绍

- 本文档将逐步向您介绍如何部署并使用 NatureTunnel 内网穿透服务图形化客户端。

## 操作步骤

### 准备工作

在 NatureTunnel 控制台 [软件下载](https://console.nrtun.com/release) 页面，下载适合您操作系统架构的最新版 NrtunLauncher 图形化客户端安装程序（例如 `NatureTunnel.Launcher Setup 1.3.0.exe`），并运行安装。

::::warning
由于程序涉及流量转发，可能会被部分杀毒软件误报为病毒，请将客户端添加至信任区，防止进程被杀。
::::

### 启动客户端

- 安装完成后，启动 NrtunLauncher 图形化客户端。

- 登录客户端后，您将看到形如下图的界面：

![客户端首页](https://docs-assets.bucket.uciu.cn/client-home-page.png)

### 启动隧道

- 在上方导航栏点击 **隧道管理**，您将看到形如下图的界面：

![隧道管理页面](https://docs-assets.bucket.uciu.cn/client-tunnel-list-page.png)

- 在这里您可以查看在浏览器控制台创建的隧道。

- 如图所示，点击 **启动隧道**：

::::tip
如果一切顺利，您可以在控制台查看到隧道已启动并成功访问您的服务。
::::

### 查看日志

- 在上方导航栏点击 **日志**，您将看到形如下图的界面：

![日志页面](https://docs-assets.bucket.uciu.cn/client-runlogs-page.png)

- 如果您的隧道启动失败，请将这部分**日志截图**，并发送至 [控制台-帮助中心](https://console.nrtun.com/help) 内的用户交流群中寻求帮助。

## 遇到问题如何求助

如果遇到问题，请添加 [控制台-帮助中心](https://console.nrtun.com/help) 内的用户交流群，发送隧道的脱敏日志友善寻求帮助。请注意，群内成员没有为您解决问题的义务，所以您需要注意您提问的方式。但在大部分情况下，群友都是很乐于助人的。
